# Documentation

This repository is currently organized around the MJX rocket chain and table-gimbal simulation workflows.

- Rocket MJX setup, training, evaluation, and acceptance commands are documented in the root `README.md`.
- Table-gimbal MJX SAC training and visual inspection commands are documented in the root `README.md`.
- Generated experiment reports, checkpoints, videos, plots, and hardware notes are intentionally kept out of the public tree.
